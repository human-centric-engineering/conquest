# F18.2 — Question fidelity

> **Written retrospectively.** This feature shipped in PR #255 (three phases, `0f2f150b4`,
> `eeccb7b09`, `089f5b9b5`) without a tracker; `f18.1.md` covers house rules only. The reasoning
> lives in [`question-fidelity.md`](../../questionnaire/question-fidelity.md) — this records what
> shipped and when.

## What was wrong

The asking prompt's standing rules tell the interviewer to ask openly, never read out a choice list,
and never request a scale number. That is right for most questions and destructive for an
instrument: a validated battery whose wording and scale are the measurement gets paraphrased into a
conversation, and the answers are no longer comparable to anyone else's.

There was no way to say "this one is a script" — and equally no way to say the opposite, that a
question is really just a note about something worth learning.

## What shipped

A five-stop per-question dial — `free` · `loose` · `balanced` · `close` · `must_ask` — stored as
`AppQuestionSlot.fidelity` (a `Float` snapped to a 0/0.25/0.5/0.75/1 grid) behind a version-level
gate, `config.questionFidelity`.

**Two no-op layers, deliberately.** `balanced` is the default stop and renders no prompt clause at
all; the gate is off by default and makes every stored value inert. Together they are what let this
ship into every existing questionnaire without changing a single prompt byte — and what let an admin
pre-set forty sliders before switching the behaviour on.

Three phases: the dial itself with its full fork/export/import carriage (phase 1); the prompt clause
and the raised satisfaction floors (`close` → 0.65, `must_ask` → 0.85) that stop a must-ask question
being parked on a weak answer (phase 2); the in-chat answer-control card for a typed `must_ask`
question, and must-ask targeting in selection (phase 3).

## Confirmed decisions

- **`resolveQuestionFidelity` is the single read seam.** Runtime code must never read
  `slot.fidelity` directly, or it applies a dial the admin never switched on.
- **It never overrides Adaptive Scope.** Out of scope means not asked, full stop — a must-ask
  question is never a reason to widen an interview. `buildSessionScope` filters before anything
  downstream sees the question.
- **Five stops, no sixth.** Each is a distinct prompt clause; a value that behaves like its
  neighbour is a lie told to the admin.
- **The card stores only the question key.** Rebuilt from the live slot on replay, so a reworded
  question does not leave a stale copy pinned in every resumed transcript.
- **Section-level bulk set**, because dragging seventy sliders one at a time is not a real workflow
  and fidelity is usually uniform within a section.
